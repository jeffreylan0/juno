# Privacy policy and terms

`privacy.md` and `terms.md` are Juno's privacy policy and terms of service, written from what the app and its services actually do. Publish them at `https://humanbn.com/privacy` and `https://humanbn.com/terms`: the app links there (Settings → Juno, and the sign-in), and so do Google's sign-in page, Stripe's public details and any store listing.

Before publishing, fill in the brackets:

| Blank | Where to find it |
| --- | --- |
| [date of publishing] | The day they go up |
| [postal address] | humanbn's mailing address (Stripe and the stores ask for one too) |
| [email provider] | The SMTP sender chosen in `supabase/README.md`, step 2 |
| [region] | Supabase → Project Settings → General → Region |
| [backup retention] | Supabase plan: 7 days on Pro (daily backups) |
| [audit log retention] | Supabase plan's auth audit log retention |
| [14] | The refund window: a decision, 14 days suggested |
| [State], [County, State] | Where humanbn is based |

Have a lawyer read both before launch: these are a careful draft, not legal advice. Keep them true as the app changes: a new service that receives student data, a new kind of data kept, or a new plan means an edit here (SECURITY.md, *Privacy and legal*).
